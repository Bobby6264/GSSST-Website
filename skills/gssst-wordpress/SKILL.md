Use the existing WordPress theme at `wp-content/themes/cic-theme`; this project runs through Docker Compose on port 8000.

- `inc/admin/admin-options.php` and `admin-views.php` own landing settings; the Customizer is not a content source.
- The landing hero uses the approved `assets/images/hero-trees-towers-v3.png` panorama (2172 × 724) with trees and two telecom towers. The artwork has no drawn wave arcs. Display it with centered `object-fit: cover`; canvas waves originate at the antenna tips `[391,198]` and `[1784,198]`, supplied by the image's `data-signal-points`. Read composition dimensions from HTML attributes, not rendered image width/height. Keep CSS placement, canvas projection and the sky mask aligned; preserve reduced-motion support, pointer waves and editable hero copy. The prior v2 SVG is retained but no longer used by the hero.
- Faculty are WordPress users with the faculty role. Their public profiles resolve at `/faculty/?member=ID`. Profile controls live in `inc/faculty.php` and `profile-tabs.js`.
- Designations require the administrator role plus manage_options. Faculty may edit their own cover, photo, social links, and academic information, but must not gain designation editing through a new endpoint.
- ERP research data is imported on demand, never on a public page render. Keep fetch failures from destroying saved records. The official faculty slug can contain dots. Reuse `inc/erp-profile.php`.
- Projects and courses are `cic_project` and `cic_course` posts. `inc/academics.php` combines published project records with deduplicated faculty ERP projects. The department project listing lives only on `/research/#projects`; faculty profiles keep their own projects. Academic navigation includes nested dropdowns, landing cards, hero buttons and footer links; connect placeholder destinations through `cic_academic_link` without replacing custom URLs.

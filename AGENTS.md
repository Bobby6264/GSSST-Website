# GSSST website maintenance

For changes to this WordPress project, read and apply [the GSSST WordPress skill](skills/gssst-wordpress/SKILL.md). Keep this project skill in the repository so future sessions can use the same content model and layout conventions.

The website is WordPress with a custom theme, not a Sites-hosted project. Use Docker Compose for PHP and database operations. Preserve existing WordPress content and unrelated working-tree edits.
